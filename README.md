# 💰 NominaPro Frontend

Frontend desarrollado en Angular para el sistema de cálculo de nómina colombiana **NominaPro**.  
La aplicación permite calcular costos empresariales, deducciones salariales y aportes de acuerdo con la legislación laboral colombiana.

---

# 🚀 Tecnologías utilizadas

- Angular 20
- TypeScript
- Tailwind CSS
- HTML5
- CSS3
- Vercel (despliegue)

---

# ✨ Características principales

## 🏢 Perfil empresa
Permite calcular:

- Salud empresarial
- Pensión empresarial
- ARL
- Caja de compensación
- ICBF
- SENA
- Cesantías
- Intereses de cesantías
- Prima
- Vacaciones
- Costo total empresarial

## 👨‍💼 Perfil empleado
Permite calcular:

- Descuento de salud
- Descuento de pensión
- Aportes independientes
- Honorarios
- Ingreso neto
- Salario neto

## 📄 Tipos de contrato soportados

- Contrato a término fijo
- Contrato a término indefinido
- Contrato de prestación de servicios

## 🎨 Diseño moderno

- Interfaz futurista
- Animaciones dinámicas
- Fondo interactivo
- Diseño responsive
- Navbar luminoso
- Efectos visuales neon
